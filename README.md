# Likvi — 3D-симулятор квадрокоптера

Likvi — браузерный прототип виртуальных олимпиад. В нём можно освоить управление квадрокоптером, пройти FPV-трассу на время и выполнить одиночный зачётный заезд на арене Московского Политеха.

## Установка и запуск

Понадобятся Node.js и npm. Выполните команды в корне репозитория.

```bash
npm ci --legacy-peer-deps
npm run dev:full
```

Откройте адрес, который Vite выведет в терминале. Обычно это `http://127.0.0.1:3000/`. Сервер физики слушает `127.0.0.1:3003`. Флаг `--legacy-peer-deps` позволяет установить зафиксированные в проекте версии зависимостей Three.js.

Для локальных тренировок можно запустить только клиент командой `npm run dev`. Чтобы запускать клиент и сервер по отдельности, используйте `npm run dev` и `npm run server` в разных терминалах.

## Режимы полёта

- **Свободный полёт.** Выберите «Стройку», «Туннели», «FPV-стадион» или классическую арену и нажмите «Свободный полёт».
- **FPV-гонка.** Выберите 1, 3 или 5 кругов и нажмите «Начать гонку». Проходите ворота в указанном порядке. Зелёные ворота обозначают текущую цель, янтарные — следующую. На финише отображается время каждого круга. Лучшие результаты хранятся в браузере по трассе и числу кругов.
- **Демо-прохождение.** Автопилот проходит один круг на выбранной FPV-трассе. Во время демо можно сменить камеру и взять управление на текущей позиции.
- **Серверный зачёт.** Выберите «Открыть режимы» → «Запустить серверный заезд». На классической арене нужно пройти пять колец по порядку. Сервер рассчитывает движение, столкновения, время и очки. После финиша результат сохраняется в `server/data/results.json` и появляется в таблице «Серверные результаты».
- **Подвижные ворота.** Выберите «Открыть режимы» → «Испытать подвижные ворота». Можно раскачать створку с пределом ±35° и поднять ворота на высоту до 4,8 м. Панель показывает угол и высоту, кнопка «Вернуть всё на старт» сбрасывает положение дрона и механизмов.

## Управление

| Клавиши | Действие | Где работает |
| --- | --- | --- |
| W / S, A / D | Наклон вперёд и назад, влево и вправо | Все режимы ручного полёта |
| Q / E | Увеличить / уменьшить газ | Все режимы ручного полёта |
| ← / → | Повернуть дрон | Все режимы ручного полёта |
| Пробел | Усиленное торможение | FPV-трассы |
| H | Установить газ для зависания | FPV-трассы |
| V | Переключить вид от первого лица и внешнюю камеру | FPV-трассы |
| R | Начать полёт или попытку заново | FPV-трассы |
| Esc | Вернуться в главное меню | Во время полёта |

Кнопка ⚙️ открывает настройки. В них доступны следящая, орбитальная и свободная камеры, а также вид от первого лица. В орбитальном и свободном режимах правая кнопка мыши вращает камеру, колесо меняет расстояние. Shift включает и выключает фиксацию камеры за дроном.

В настройках можно включить траекторию, звук, частицы и отладочный показ коллайдеров. Параметр «Показать HUD» управляет классической приборной панелью. На FPV-трассах отдельный интерфейс показывает таймер, круги, мини-карту, направление до ворот и телеметрию, включая газ, крен, тангаж и вертикальную скорость.

## Физика и графика

Контроллер полёта задаёт тягу и вращающий момент, а Rapier3D рассчитывает движение и контакты с шагом 1/60 секунды. Дрон массой 1 кг использует составные коллайдеры. Непрерывное обнаружение столкновений (CCD) помогает находить контакты при быстром движении, а `three-mesh-bvh` уточняет место удара и пересечение с контуром воды. Сильный удар о твёрдую поверхность запускает анимацию модели, частицы и след в точке контакта.

| Параметр | Учебный профиль и серверный зачёт | FPV-профиль |
| --- | ---: | ---: |
| Максимальная суммарная тяга | 27,2 Н | 58 Н |
| Газ для зависания | ≈36% | ≈33% |
| Максимальный целевой наклон | ≈30° | 60° |

Сцена использует материалы PBR, мягкие тени, небо и туман. Статические детали FPV-трасс объединены по участкам карты и материалам, повторяющийся декор отрисовывается группами.

## Структура проекта

```text
likvi/
├── src/
│   ├── components/  # Сцены, модель дрона и интерфейс
│   ├── camera/      # Режимы камеры
│   ├── hooks/       # Ввод с клавиатуры и шаг симуляции
│   ├── physics/     # Модель полёта, трассы и коллизии
│   ├── network/     # Клиент серверного зачёта
│   └── store/       # Состояние приложения в Zustand
├── server/          # Серверная симуляция и сохранение результатов
├── public/          # Статические файлы
├── scripts/         # Запуск и измерения
├── tests/           # Автоматические тесты
└── docs/            # Документация и отчёты
```

Клиент использует React 18, Three.js, React Three Fiber, Drei, Zustand и React Spring. Сервер работает на Node.js, а Vite запускает и собирает клиент.

## Проверки

| Команда | Что проверяет или запускает |
| --- | --- |
| `npm test` | Автотесты физики, трасс, автопилота и серверного зачёта |
| `npm run lint` | Проверку исходного кода с ESLint |
| `npm run build` | Сборку клиента в `dist/` |
| `node scripts/benchmark-bvh.mjs` | Замер скорости геометрических запросов |
| `node scripts/measure-fpv-flight.mjs` | Замер разгона и торможения учебного и FPV-профилей |
