# 🚁 Продвинутый 3D Симулятор Квадрокоптера

Браузерный прототип виртуальных олимпиад с 3D-симулятором квадрокоптера.

Физическая подсистема обновлена 13.10.2026: дрон управляется Rapier, работают
коллайдеры препятствий, BVH-запросы, подвижные ворота с сочленениями,
анимации столкновения через react-spring, частицы и динамические следы ударов.
Подробное описание реализации, выполненных
этапов паспорта и сценарий защиты: [часть Жердина Руслана](docs/physics-ruslan.md).
Полный индивидуальный отчёт: [текст в репозитории](docs/report-ruslan-full.md)
и [оформленный документ Word](docs/report%20ivan.docx).
Добавлен зачётный режим с серверной физикой, проверкой маршрута и отдельным
хранилищем результатов: [запуск и протокол сервера](docs/server-physics.md).

Проверки: `npm test` — 48 тестов; `npm run lint`; `npm run build`.
Замер BVH: `node scripts/benchmark-bvh.mjs`.

## ✨ Особенности

### 🎮 Физика полета
- Динамическое составное тело Rapier массой 1 кг
- Тяга, стабилизация наклона и курса, сопротивление воздуха
- Фиксированный шаг 1/60 с и интерполяция изображения
- Контакты с землёй и препятствиями, мягкая посадка и аварии
- CCD для быстрых столкновений и точные запросы через BVH
- Испытание шарнирной створки (±35°) и подъёмных ворот (ход 0–4,8 м)
- Учёт относительной скорости при столкновении с движущимся препятствием
- Отдельный серверный зачётный режим с подтверждением маршрута и результатов

### 🎨 Продвинутая графика
- **PBR материалы** - физически корректное освещение
- **Тени** - высококачественные мягкие тени (4096x4096)
- **Система частиц** - эффекты от винтов
- **Столкновения** - пружинная реакция корпуса, искры, капли и круг на воде
- **Динамические декали** - след удара на геометрии поверхности до сброса попытки
- **Реалистичный ландшафт** - процедурная генерация рельефа
- **Окружение** - небо, звезды, освещение

### 📊 Полный HUD интерфейс
- **Искусственный горизонт** - индикатор наклона
- **Параметры полета** - высота, скорость, батарея
- **Индикаторы управления** - pitch, roll, yaw
- **GPS координаты** - позиция в пространстве
- **Статистика** - время полета, максимальная высота, дистанция

### 📹 Система камер
- **Следящая камера** - автоматическое следование за квадрокоптером
- **Камера от первого лица** - FPS вид из квадрокоптера
- **Орбитальная камера** - круговой обзор
- **Свободная камера** - полный контроль позиции

### 🎯 Дополнительные функции
- **Визуализация траектории** - отображение пути полета
- **Настройки** - полная кастомизация параметров
- **Панель управления** - подсказки по управлению
- **Статистика полета** - отслеживание всех параметров

## 🚀 Установка

```bash
npm ci --legacy-peer-deps
```

В сохранённом дереве зависимостей есть существующий конфликт peer-зависимости
Three.js у gainmap-js. Флаг `--legacy-peer-deps` нужен для воспроизведения этого
дерева. При сборке сохраняется предупреждение `BatchedMesh` из зависимости Drei;
версия Three.js в рамках физической части не обновлялась.

## 🎮 Запуск

Для клиента вместе с серверной физикой:

```bash
npm run dev:full
```

Открыть адрес из терминала и выбрать **Открыть режимы → Запустить серверный заезд**.
Сервер работает на `127.0.0.1:3003`; результаты сохраняются в `server/data/results.json`.
Для раздельного запуска использовать `npm run server` и `npm run dev` в двух терминалах.

Только клиент с локальными тренировками:

```bash
npm run dev
```

Приложение откроется в браузере на http://localhost:3000

Для демонстрации сочленений: **Открыть режимы → Испытать подвижные ворота**.
Кнопки раскачивают оранжевую створку и поднимают голубую; панель показывает
фактический угол и высоту. «Вернуть всё на старт» сбрасывает и дрон, и механизмы.
Этот режим не добавляет препятствия в обычный одиночный заезд.

## 🕹️ Управление

### Основное управление
- **W** - наклон вперед (pitch down)
- **S** - наклон назад (pitch up)
- **A** - наклон влево (roll left)
- **D** - наклон вправо (roll right)
- **Q** - увеличить газ (throttle up)
- **E** - уменьшить газ (throttle down)
- **← →** - поворот (yaw)

### Камера
- **Мышь** - управление камерой
- **Колесо мыши** - приближение/отдаление

### Меню
- **⚙️** (кнопка в правом верхнем углу) - открыть настройки
- **ESC** - пауза (в разработке)

## 🎯 Параметры физики

- Масса квадрокоптера: 1 кг
- Максимальная суммарная тяга: 27,2 Н
- Газ для зависания без наклона: около 36%
- Шаг симуляции: 1/60 с
- Максимальный целевой наклон: около 30 градусов
- Размеры коллайдеров, коэффициенты трения и упругости: `src/physics/dronePhysics.js`

## 🎨 Особенности реализации

### Физика

Движением управляет Rapier через силы и моменты. Three.js отображает положение
физического тела. Zustand передаёт телеметрию интерфейсу и хранит события аварий.
BVH строится один раз для статической геометрии, уточняет поверхность удара и
проверяет точный контур реки. Модель полёта учебная, со стабилизацией наклона.

### Графика
- PBR материалы для реалистичного освещения
- Высококачественные тени с большим разрешением
- Система частиц для эффектов
- Процедурный ландшафт с рельефом
- Динамическое освещение

### Интерфейс
- Полный HUD с искусственным горизонтом
- Индикаторы всех параметров полета
- Статистика в реальном времени
- Настройки с возможностью кастомизации


Создано с использованием React Three Fiber, Three.js и Rapier Physics.
